## 🚢 Vercel Deployment Instructions

1. Push this repository to **GitHub**:
   ```bash
   git init
   git add .
   git commit -m "feat: Ahmed Younis portfolio with authentic dashboards and contact links"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/ahmed-younis-portfolio.git
   git push -u origin main
   ```
2. Log in to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import your repository and click **"Deploy"**.
